# BioSeq Toolkit

**Semanas:** 04–06 y 13–20. **Estado:** sin iniciar.

Procesa cadenas didácticas de ADN y archivos pequeños. En S06, entrega conteo, reverso complementario y transcripción simbólica con tests. En S20, incorpora validación, alineamiento, QC y pipeline reproducible.

- Fija manejo de cadenas vacías, minúsculas, N, símbolos inválidos e identificadores duplicados.
- Prueba orientación, conservación de longitud y doble reverso complementario.
- Antes de publicar v1.0, ejecuta la suite, incluye comando de ejemplo y registra versiones y resultados.
- Usa el archivo de juguete en [examples/toy.fasta](examples/toy.fasta).
