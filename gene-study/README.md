# Estudio de un gen

**Semanas:** 07–12. **Estado:** sin iniciar.

Analiza el gen humano LCT y dos variantes documentadas. Para cada registro guarda fuente, organismo, ensamblaje, transcrito, coordenada, identificador y evidencia. Distingue descripción, asociación e inferencia causal.

Entrega una tabla y un informe breve de alcance educativo. La evidencia es pública y corresponde a registros de referencia. No incluyas información genética personal.
