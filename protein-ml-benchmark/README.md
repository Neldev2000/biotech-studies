# Protein ML Benchmark

**Semanas:** 21–28. **Estado:** sin iniciar.

Compara un baseline de composición con embeddings congelados para clasificar localización subcelular en proteínas vegetales anotadas.

- Fija etiquetas, origen, exclusiones y partición por familia antes de comparar.
- Registra macro-F1, matriz de confusión e incertidumbre por grupo.
- Conserva el conjunto de prueba para el cierre y documenta tamaño, sesgos y casos ambiguos.
- Si los grupos son insuficientes, entrega evidencia de inviabilidad y resultados de prueba en datos de juguete claramente identificados.
